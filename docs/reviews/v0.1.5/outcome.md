## 技术债与认知偏差

### 预期偏差

1. **检索指标始终返回 0**：source 路径格式不匹配，已通过 normalize_source() 解决
2. **测试覆盖**：原计划覆盖核心模块，实际覆盖了所有模块（356 个测试）

### AI 盲区

1. **pathlib vs os**：排查幽灵文件夹问题时，忽略了 pathlib.Path.mkdir 与 os.mkdir 的区别
2. **Anthropic API system 参数**：原实现将 system prompt 拼接到 user message，降低了指令遵循质量

## Prompt 优化记录（供下一轮迭代）

1. **检查顺序**：先检查前置条件，再执行副作用操作（如创建目录）
2. **API 规范**：使用 API 的专用参数（如 Anthropic 的 system 参数），而非拼接
3. **资源管理**：使用上下文管理器（`with` 语句）管理资源
