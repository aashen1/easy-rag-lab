## 需求描述

要求输出完整的透明版实验报告，包含以下所有信息：

1. **预置问题与答案**：测试集中的所有问题及其 expected answer
2. **问题 embedding**：每个问题的向量表示
3. **Recall 向量**：检索阶段召回的 chunks 及其排序
4. **Chunk 解码信息**：每个 chunk 的原文、来源文档、页码
5. **LLM 提示词**：发送给 LLM 的完整 prompt（含 system prompt + contexts + question）
6. **LLM 回复**：LLM 的原始回复文本
7. **指标计算过程**：每个指标的计算中间结果和最终值

---

## 目的

- 确认基线性能是否虚高
- 排查是否存在自问自答虚高
- 验证评测指标计算是否正确
- 为后续优化提供可追溯的实验记录

---

## 实现思路

1. 在 `experiment.py` 的 `run_experiment()` 中增加 verbose 模式开关
2. 逐题记录完整的中间数据
3. 输出为结构化 JSON + 可读 Markdown 双格式
4. 估算：每个问题的完整记录约 5-10KB，100 问约 0.5-1MB
