# FEAT-028: 配置验证系统

## 需求描述

当前 `config.yaml` 使用 `yaml.safe_load()` 直接加载，无任何验证。需要引入 Pydantic 模型进行：

1. **必填项校验**：确保关键配置项存在
2. **类型校验**：确保配置值类型正确（如 chunk_size 必须是 int）
3. **范围校验**：确保配置值在合理范围内（如 chunk_size > 0, overlap < chunk_size）
4. **默认值填充**：为可选配置项提供合理默认值

---

## 当前风险

- 配置项拼写错误不会报错，静默使用默认值
- 类型错误（如 chunk_size 写成字符串）在运行时才暴露
- 缺少必填项时，错误信息不明确

---

## 实现思路

1. 定义 Pydantic 配置模型（嵌套结构，对应 config.yaml 层级）
2. 在 `load_config()` 中加载 YAML 后用 Pydantic 验证
3. 提供清晰的错误信息，指出哪个字段有问题
4. 保持向后兼容：新增字段都有默认值
