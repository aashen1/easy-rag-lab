# Streamlit Web Demo 使用指南

本文档介绍如何使用 Easy RAG Lab 的 Web 可视化界面。

---

## 快速启动

```bash
pixi run web
```

浏览器将自动打开 `http://localhost:8501`。

---

## 界面概览

Web 界面包含两个标签页：

| 标签页 | 功能 |
|--------|------|
| 💬 问答演示 | 输入问题，获取答案和检索详情 |
| 📖 系统信息 | 查看 RAG 链路流程图和技术栈 |

---

## 问答演示页

### 侧边栏配置

| 配置项 | 说明 |
|--------|------|
| **Meal** | 选择数据集快照，或新建 Meal |
| **检索策略** | vector（向量检索）/ bm25 / hybrid（混合检索） |
| **Top-K** | 召回文档数量（1-10） |
| **启用 Reranker** | 使用重排序模型优化检索结果 |
| **启用查询改写** | 使用 HyDE 策略改写查询 |

### 新建 Meal

选择 **"+ 新建 Meal"** 后，可配置：

| 配置项 | 说明 |
|--------|------|
| Meal 名称 | 可选，留空自动生成时间戳名称 |
| 采样方式 | 按页数 / 按文件数 / 按比例 |
| 目标页数/文件数量/采样比例 | 根据采样方式动态显示 |
| 随机种子 | 用于可重复采样 |

点击 **"创建 Meal"** 后，系统会自动完成：
1. PDF 采样
2. PDF 解析
3. 文档分块
4. 向量索引构建

### 问答交互

1. 在输入框输入问题
2. 点击 **"提交"** 按钮
3. 等待检索完成，查看结果

### 结果展示

问答完成后，显示以下内容：

| 区域 | 内容 |
|------|------|
| **答案** | LLM 生成的回答 |
| **来源文档** | 检索到的文档列表，显示文件名和相关度分数 |
| **检索片段** | 具体的文本片段，可展开查看完整内容 |
| **评分详情** | JSON 格式的评分信息 |
| **Token 消耗** | 输入/输出/总计 Token 数量 |

### 清空结果

点击 **"清空"** 按钮可清除当前问题和结果。

## 系统信息页

展示以下内容：

- **RAG 链路流程图**：PDF 解析 → 分块 → 向量化 → 检索 → 生成
- **技术栈**：PDF 解析、Embedding、向量存储、LLM、评测
- **使用指南**：命令行使用说明和文档链接

## 常见问题

### Q: 切换标签页后结果丢失？

A: 当前版本使用 Tabs 方案，问题和结果会自动保存。如果遇到问题，请检查是否点击了"清空"按钮。

### Q: 新建 Meal 很慢？

A: 新建 Meal 需要完成 PDF 解析、分块、向量索引构建，首次可能需要几分钟。后续使用已创建的 Meal 会很快。

### Q: 如何使用已有的 Meal？

A: 在侧边栏的 Meal 下拉菜单中选择已有的 Meal 即可。Meal 列表从 `data/meals/` 目录自动加载。
