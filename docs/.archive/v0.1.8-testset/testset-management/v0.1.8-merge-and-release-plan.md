```bash
git checkout dev
git merge --no-ff fix-eval -m "release: prepare v0.1.8 - evaluation metrics expansion and TestSetManager system

Major changes since v0.1.7:
- Add Context Precision, Context Recall, chunk-level, dedup, and FPR metrics
- Introduce TestSetManager for structured test set lifecycle management
- Reorganize exp_configs into templates and categorized structure
- Fix NDCG calculation, question generation, and chunker config hash issues
- Add question validity checking and equivalence group support
- Enhance experiment reports with technology summary and full config snapshots
```

## 四、CHANGELOG 草案（精简版）

```markdown
## [0.1.8] - 2026-04-20

Evaluation system reliability improvements and TestSetManager architecture.

### Added

- Context Precision and Context Recall metrics for generation quality evaluation
- Chunk-level retrieval metrics, deduplication metrics, and False Positive Rate
- Equivalence group support for document-level metric normalization
- TestSetManager system for structured test set lifecycle management
- Question validity checking to filter unanswerable questions
- `--name` parameter for test set generation CLI
- Template-based experiment configuration structure

### Changed

- Reorganized exp_configs into categorized structure (baseline/, experiments/, golden_tests/, smoke_tests/)
- Integrated new metrics into evaluation pipeline and experiment reports
- Added source_chunks field to document-level question generation

### Fixed

- NDCG calculation deduplication to ensure values in [0,1] range
- source_files for irrelevant/missing question types
- Chunker config hash to include strategy and semantic parameters
- Question generation not reaching target count
```
