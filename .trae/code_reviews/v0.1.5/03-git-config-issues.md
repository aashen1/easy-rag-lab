## 3. pixi.toml 配置问题

### 3.1 平台兼容性

```toml
platforms = ["win-64"]
```

仅声明 Windows 平台。torch 版本 `2.6.0+cu126` 是 CUDA 专用，Linux/macOS 用户无法直接使用。

**影响**：开源后非 Windows 用户无法直接 `pixi install`。

**建议**：
- 在 README 中明确标注"当前仅支持 Windows + CUDA 12.6"
- 或添加多平台支持：`platforms = ["win-64", "linux-64"]`，并在 dependencies 中使用平台条件区分 torch 版本

### 3.2 PyPI 镜像源配置

```toml
[pypi-options]
index-url = "https://pypi.mirrors.ustc.edu.cn/simple"
extra-index-urls = ["https://pypi.org/simple"]
index-strategy = "unsafe-best-match"
```

使用中科大 PyPI 镜像作为主源。对国内用户友好，但海外用户可能访问缓慢。

**建议**：在 README 中说明镜像源配置，或提供切换为官方源的方法。

### 3.3 torch 版本锁定

```toml
torch = { version = "==2.6.0+cu126" }
torchvision = { version = "==0.21.0+cu126" }
```

torch 版本精确锁定为 CUDA 12.6 专用构建。注释中已说明"Feel free to adjust based on your platform"，但开源用户可能不知道如何修改。

**建议**：在 README 中添加 torch 版本配置指南，说明如何根据平台和 CUDA 版本调整。

## 4. config.yaml 配置审查

### 4.1 API Key 引用方式（合规）

```yaml
llm_presets:
  default:
    api_key: "LLM_API_KEY"  # 环境变量名，非实际值
    base_url: "LLM_BASE_URL"
```

所有 `api_key` 和 `base_url` 字段均使用环境变量名引用，实际值通过 `.env` 注入。**合规。** ✅

### 4.2 设备配置

```yaml
embedding:
  device: "cuda"
```

硬编码为 CUDA。无 GPU 的用户需手动改为 `"cpu"`。

**建议**：在 config.yaml 中添加注释说明，或实现自动检测：

```yaml
embedding:
  device: "cuda"  # 改为 "cpu" 如果没有 NVIDIA GPU
```
